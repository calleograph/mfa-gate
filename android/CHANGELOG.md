## [0.2.0] — 2026-11-18

### Изменено

- Приложение называется MFA Gate Authenticator. applicationId и пакет теперь `io.github.calleograph.mfagate`. Это новое приложение для Android, поэтому прежнюю установку нужно удалить, а серверы привязать заново.
- Ссылка привязки теперь `mfagate://enroll`, ссылки со старой схемой отклоняются. Первая строка подписи решения: `mfa-gate-decision-v1`.
- FCM-сервис переименован в `MfaGateMessagingService`. Переменные подписи: `MFA_GATE_KEYSTORE`, `MFA_GATE_KEYSTORE_PASSWORD`, `MFA_GATE_KEY_ALIAS`, `MFA_GATE_KEY_PASSWORD`.
- Оформление переведено на тему «Стекло» из веб-интерфейса эталонный проект: голубой градиентный фон, полупрозрачные светлые карточки с обводкой и мягкой тенью, синий акцент, светлый и тёмный варианты. Все токены собраны в `ui/theme/Theme.kt`.
- Ошибки сервера читаются в формате `{code, message}`. Если код ошибки приложению не знаком, показывается текст сервера.

### Добавлено

- Экран приветствия при первом запуске с одной главной кнопкой «Сканировать QR-код», ручным вводом ссылки и вариантом «только одноразовые коды».
- После привязки приложение объясняет, зачем нужны уведомления, и запрашивает `POST_NOTIFICATIONS`. Если в разрешении отказано, кнопка ведёт в настройки.
- Если камера запрещена или её нет, приложение сразу открывает ручной ввод ссылки и предлагает перейти в настройки разрешений. То же работает при добавлении кода TOTP.
- Привязка к серверу по `http://` теперь работает и в release, но только после явного подтверждения риска («Соединение без шифрования — только для изолированной тестовой сети»). Такой сервер помечен в списке.
- Обратный отсчёт запроса считается по времени сервера: `server_time` из списка запросов, для одного запроса — заголовок `Date`.
- Push-сигнал с `device_id` сразу находит нужную учётную запись, без перебора серверов.
- Кнопка «Повторить» у сетевых ошибок на экране запросов и при привязке.

### Исправлено

- Повторное подтверждение исключено: после нажатия обе кнопки решения заблокированы до ответа сервера. Ответы 409, 410 и 404 закрывают карточку с пояснением («Запрос уже обработан…»), и кнопок решения на ней больше нет. Истёкший по времени сервера запрос тоже теряет кнопки.

## [0.1.0] — 2026-11-18

Первая версия: привязка по QR, подтверждение входа подписью ECDSA P-256 из Android Keystore после биометрии или PIN, TOTP без сети, сборки `foss` и `gms`.
