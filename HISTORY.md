# Журнал изменений проекта

## 2026-11-18 — восстановление сборки
- Сделано: возвращён отсутствовавший `vite.config.js` (стандартный Laravel + Tailwind 4), на него ссылаются оба Dockerfile (`COPY vite.config.js`), без него образы не собирались. Неполный `vendor/` восстановлен из `composer.lock`.

- Результат: `npm run build` собирается; `php artisan test` — 20 тестов, все проходят.
- Незавершено: редизайн интерфейса не выполнялся, работа перенесена в новый проект Twofold.

## 2026-11-18 — фундамент новой реализации (рабочее название Twofold, 0.1.0)
- Сделано: исследование (эталонный проект — сервер и Android, собственные проекты, privacyIDEA и pi-authenticator с лицензиями, Multifactor по публичной документации, Ideco/OpenVPN/NPS, VPN-клиент); 13 ADR и модель угроз; сервер (FastAPI, собственный RADIUS, push с подписью ECDSA, TOTP, LDAP/AD, политики, REST API v1, Device API, worker, CLI); Docker Compose и twofoldctl (установка, обновление с автооткатом, откат, копии, восстановление, диагностика); веб-панель; Android-приложение (foss/gms); документация, CI/CD, сканер частных данных; независимое ревью кода — исправлены 15 находок (захват учётных записей администраторов оператором, обход второго фактора через первичную настройку TOTP, повторное использование push-входа в панель, присоединение чужой попытки к push, отказ доставки push из-за одного устройства, захват записи доменным логином, обход блокировки через DOMAIN\user/UPN, перебор TOTP администратора, перечисление логинов через RADIUS, раздувание кэша повторов подделками, откат к прямым группам AD при сбое, блокировка цикла событий argon2, последовательная отправка push, зависание LISTEN, смена ресурса ключом API) и удержание соединений БД long-poll'ом.
- Основные файлы: `server/twofold/**`, `server/tests/**`, `server/migrations/versions/0001…0002`, `server/web/**`, `deploy/{compose.yml,.env.example,twofoldctl}`, `scripts/{e2e.sh,check_private_data.py}`, `android/**`, `docs/**`, `.github/workflows/{ci,release}.yml`.
- Результат: юнит-тесты сервера и сквозные на стенде — 78 passed; LDAP на настоящем OpenLDAP — 17 passed; изолированный Docker-стенд — см. `docs/testing.md`; Android — 28 JVM-тестов, debug и release APK обоих flavors собираются; панель проверена в браузере на 7 ширинах.
- Незавершено: проверка на реальном VPN-шлюзе и Android-устройстве, FCM на реальном проекте Firebase; RADIUS Accounting, number matching, портал самообслуживания, SMTP-приглашения, резервные коды в API; публикация на GitHub не выполнялась.

## 2026-11-18 — объединение в MFA Gate 0.2.0
- Сделано: прежняя реализация на Laravel упакована в локальный архив `_archive/mfa-gate-laravel-2026.06.15.tar.gz` (вне публикации; файлы остаются в рабочем каталоге и исключены из Git через `.gitignore`); новая реализация перенесена в корень и переименована в MFA Gate (пакет `mfa_gate`, переменные `MFA_GATE_*`, утилита `mfagatectl`, образ `ghcr.io/calleograph/mfa-gate`, схема привязки `mfagate://`, подпись `mfa-gate-decision-v1`); ограничитель частоты входа перенесён в PostgreSQL (общий для нескольких экземпляров api); первый администратор создаётся установщиком с временным паролем и обязательной сменой; cookie `Secure` выставляется по схеме запроса (HTTP-установка и HTTPS через reverse proxy); установщик All-in-One `install.sh`; `mfagatectl`: сборка образа из исходников при недоступном реестре, `admin-init`, `uninstall`; исследования обезличены.
- Основные файлы: `install.sh`, `VERSION`, `deploy/mfagatectl`, `deploy/.env.example`, `server/mfa_gate/api/{auth,deps,device}.py`, `server/mfa_gate/{models,cli,worker,config}.py`, `server/migrations/versions/0003_*`, `server/tests/test_stack.py`, `.gitignore`.
- Результат: 79 тестов сервера (57 юнит + 22 сквозных на стенде с двумя экземплярами api), лимит входа общий для экземпляров.
- Незавершено: тема «Стекло» и экран смены пароля в панели, Android под новым названием, проверка установки на чистом сервере, публикация.
