# Использованные собственные наработки

Проверено чтением кода (2026-11-18). Доноры — более ранние собственные проекты автора на Python (донор A — сервис аудита на FastAPI, донор B — шлюз к языковым моделям на FastAPI), эталонный проект — платформа видеовстреч с Docker-установкой и Android-клиентом.

## Что взято в MFA Gate

| Механизм | Донор | Путь в доноре | Как использовано в MFA Gate |
|---|---|---|---|

| Шифрование секретов AES-256-GCM с версией формата и AAD | донор A | `backend/app/security/secretbox.py` | перенесён: `server/mfa_gate/security/secretbox.py` |
| LDAP: несколько доменов, вложенные группы (1.2.840.113556.1.4.1941) с откатом к memberOf, диагностика входа | донор A | `backend/app/auth/ldap.py` | основа `server/mfa_gate/services/ldap.py` |
| Строгий LDAPS (CERT_REQUIRED, свой CA), запрет пустого пароля и анонимного bind, разбор подкодов AD (525/52e/530/531/532/533/701/773/775) | донор B | `<донор B>/ldap/client.py`, `<донор B>/ldap/diagnostics.py` | правила перенесены в `services/ldap.py` |

## Ошибки доноров, которые не переносятся

- mfa-gate TOTP: `verify($code, null, 1)` в otphp 11 задаёт допуск в секундах, а не шагах — окна нет; повтор кода не отклоняется. Взята реализация донор A.
- mfa-gate блокировки: счётчик не сбрасывается после истечения блокировки и обновляется не атомарно; блокировка только по логину позволяет заблокировать чужой вход. В MFA Gate счётчик сбрасывается и обновляется одним `UPDATE`.
- mfa-gate OpenVPN-скрипт передаёт пароль и секрет аргументами curl (видны в `ps`). В MFA Gate основной путь — RADIUS; для REST-интеграции секреты передаются через stdin/файл.
- mfa-gate: при недоступной таблице политик действуют значения по умолчанию (fail-open). В MFA Gate отсутствие подходящей политики означает «MFA обязателен».

## Не источники кода

Остальные просмотренные проекты либо не содержат нужных механизмов, либо дублируют решения доноров на других стеках, либо принадлежат другим авторам — их код не переносился.

## Отложено

- SMTP (донор донор B `<донор B>/mail/smtp.py` с пошаговой диагностикой и фейковым SMTP для тестов) — для приглашений по email.
- Резервные коды (донор A `hash_backup` с HMAC-перцем и гашением одним UPDATE) — функции уже есть в `security/totp.py`, API ещё нет.
- Роли по группам AD (донор A `LdapStore.decide`).
