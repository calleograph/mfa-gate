# 0011. Android-приложение

**Решение.** Отдельный Gradle-проект `android/` с независимой версией. Организация проекта: AGP 9.5 со встроенным Kotlin, version catalog, Compose + Material3, версия из файла VERSION, подпись из переменных окружения или файла вне Git, SecretBox на ключе Keystore, запрет резервного копирования данных; BiometricPrompt + CryptoObject для подписи, сканер QR (ZXing, Apache-2.0 — без ML Kit), TOTP-генератор, flavors `foss`/`gms`.

**Проверка.** На сервере разработки нет эмулятора и KVM: проверяются сборка APK и JVM-тесты логики. Поведение на устройстве (биометрия, push, фон) требует ручной проверки на телефоне или эмулятора в CI.
