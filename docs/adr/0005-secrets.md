# 0005. Секреты

**Решение.**
- Мастер-ключ 32 байта: файл `data/secrets/master.key`, передаётся контейнерам как Docker secret, в БД и Git не хранится; без него резервная копия бесполезна — хранить отдельно.
- Обратимо хранимые секреты (TOTP, RADIUS shared secret, пароль сервисной УЗ LDAP, push-токены): AES-256-GCM с версией формата и AAD, привязанной к записи (`totp:<id>`, `radius:<id>`, `ldap:<id>`, `push:<id>`) — шифртекст нельзя переставить в другую запись.
- Пароли локальных пользователей — argon2id. Высокоэнтропийные токены (секрет устройства, ключ API, токен привязки, сессия, аварийный код) — SHA-256, сравнение за постоянное время.
- Журнал: ключи с `password/secret/token/code/otp/signature/key/challenge` маскируются всегда; `diagnose` не создаёт архив, если находит в нём значения секретов.

**Не сделано.** Ротация мастер-ключа (формат версионирован — добавляется командой перешифрования); HSM/Vault.
