# 0012. Лицензия

**Решение.** Apache-2.0. Зависимости сервера — MIT/BSD/Apache-2.0; ldap3 — LGPL-3.0 (используется как библиотека без изменений — совместимо). Android-зависимости — Apache-2.0; Firebase SDK — только в сборке `gms`.

**Чужой код.** Код под копилефт-лицензиями (AGPL, GPL) и код закрытых продуктов в проект не переносится. Сторонние компоненты — только под разрешительными лицензиями, перечислены в `NOTICE`.
