# 0012. Лицензия

**Решение.** Apache-2.0. Зависимости сервера — MIT/BSD/Apache-2.0; ldap3 — LGPL-3.0 (используется как библиотека без изменений — совместимо). Android-зависимости — Apache-2.0; Firebase SDK — только в сборке `gms`.

**Что не заимствуется.** privacyIDEA (AGPL-3.0) и его модуль FreeRADIUS (GPL-2.0) — изучены только протоколы и идеи. Multifactor — закрытый продукт, лицензия адаптеров запрещает производные работы: повторяется только функциональная модель. Код собственных проектов (донор A, донор B, эталонный проект, MFA-Gate) переносится с адаптацией.
