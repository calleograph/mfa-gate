# 0007. LDAP / Active Directory

**Решение.** ldap3 в `asyncio.to_thread`. Механизмы, проверенные в других проектах команды: LDAPS по умолчанию с `CERT_REQUIRED` и своим CA, запрет пустого пароля и анонимного bind, разбор подкодов AD, вложенные группы через `LDAP_MATCHING_RULE_IN_CHAIN` (AD) или рекурсивный обход (OpenLDAP), несколько контроллеров (`ServerPool FIRST`), пошаговая диагностика DNS → TCP → TLS → bind → base DN → поиск → bind пользователя → группы для каждого контроллера.
- Пользователи каталога создаются при первом входе (связь по objectGUID/entryUUID) или заранее из панели (поиск в каталоге).
- Недоступность каталога = отказ во входе (`directory_unavailable`), без обхода.

Подробности и тесты: [docs/ldap.md](../ldap.md).
