# 0004. Доставка push

**Решение.** Push — только сигнал `{type, request_id}`; данные телефон забирает по HTTPS. Провайдеры за одним интерфейсом в worker: FCM HTTP v1 (JWT service account подписывается через `cryptography`, без Google SDK на сервере), HMS (экспериментально), UnifiedPush (только хосты из белого списка — защита от SSRF), `none`. Без push-канала приложение держит long-poll `GET /requests?wait=25`, пока открыто, и проверяет запросы WorkManager'ом.

**Android.** Две сборки: `gms` (Firebase, параметры проекта приходят с сервера — без `google-services.json` в репозитории, каждая организация подключает свой Firebase) и `foss` (без Google).

**Последствия.** Сервер не зависит от одного поставщика; у FOSS-сборки без UnifiedPush push приходит только при открытом приложении — это отражено в диагностике.
