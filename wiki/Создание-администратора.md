# Создание администратора

## Первый администратор — автоматически

Установщик сам создаёт главного администратора `admin` (роль `superadmin`) с временным паролем и показывает пароль один раз в итоговом блоке. При первом входе панель требует сменить пароль и подключить второй фактор — см. [Первоначальная настройка](Первоначальная-настройка.md).

Если администратор уже существует (повторный запуск `install.sh`), установщик его не трогает и пишет «главный администратор уже существует (пароль не менялся)».

Вручную то же действие выполняет команда:

```bash
sudo mfagatectl admin-init
```

**Ожидаемый результат:** либо `главный администратор admin создан` и строка `пароль (показывается один раз): …`, либо `главный администратор уже есть — пропущено`.

## Дополнительные администраторы — в панели

Держите минимум двух главных администраторов: если один потеряет телефон, второй сможет помочь без доступа к серверу.

### Локальный администратор

1. «Пользователи» → «Добавить пользователя».
2. Источник учётной записи — «Локальный». Логин, имя, пароль (не короче 12 символов).
3. «Роль в панели управления» — выберите роль (таблица ниже). Нажмите «Создать».
4. Передайте логин и пароль сотруднику безопасным способом.

**Ожидаемый результат:** пользователь появился в списке с ролью.

**Как проверить:** сотрудник входит в панель; при первом входе панель просит подключить TOTP. В «Журнале» появляется событие входа `admin.login`.

### Администратор из Active Directory

Пользователь из каталога появляется в MFA Gate после первого успешного входа (или его можно завести заранее с источником «Из каталога» и тем же логином). Откройте его карточку → «Роль в панели управления» → выберите роль. Пароль у такого администратора — доменный, меняется в AD.

### Роли

| Роль | Что может |
|---|---|
| `superadmin` — главный администратор | всё, включая назначение ролей другим администраторам |
| `admin` — администратор | все разделы на чтение и изменение; администраторов только видит |
| `operator` — оператор | пользователи и устройства: привязка телефона, TOTP, разблокировка; остальное — только чтение |
| `auditor` — аудитор | только чтение всех разделов, включая журнал |

Назначать роли может только `superadmin`. Последнего активного главного администратора нельзя лишить роли, отключить или удалить. Полная таблица прав: [docs/admin-guide.md](https://github.com/calleograph/mfa-gate/blob/main/docs/admin-guide.md#роли-администраторов).

## Восстановление доступа

### Забыт пароль локального администратора

```bash
sudo mfagatectl admin admin
```

Вместо второго `admin` укажите нужный логин. Команда задаёт новый случайный пароль и снимает блокировку. Если такого логина нет — создаёт нового главного администратора.

**Ожидаемый результат:**

```text
главный администратор admin создан
пароль (показывается один раз): …
при первом входе в панель будет предложено подключить TOTP
```

Строка «создан» печатается и при сбросе пароля существующей записи. Второй фактор администратора при этом сохраняется.

**Как проверить:** вход в панель с новым паролем; в журнале событие `admin.created_cli` с уровнем `warning`.

Для администратора из каталога команда не работает (`пользователь из каталога: … пароль меняется в каталоге`) — сбросьте пароль в AD.

### Потерян второй фактор (телефон и TOTP)

```bash
sudo mfagatectl emergency admin
```

**Ожидаемый результат:**

```text
одноразовый аварийный код для admin (действует 15 мин, заменяет второй фактор один раз):
1a2b3c-4d5e6f-7a8b9c
```

Войдите в панель: логин, **пароль**, а на шаге второго фактора введите аварийный код вместо кода из приложения. Сразу после входа подключите новый фактор: откройте свою карточку в «Пользователях», удалите старый TOTP и выпустите новый, или привяжите новый телефон.

**Как проверить:** в «Журнале» события `admin.emergency_code_issued` и `admin.emergency_access` с уровнем `critical`. Так и должно быть: каждый аварийный вход виден.

Экран «Подключите второй фактор» при входе появляется, только если у учётной записи нет подключённого TOTP и никогда не было привязанного телефона (даже отозванного) — это защита от подмены фактора тем, кто узнал пароль. Поэтому после потери телефона войдите по аварийному коду и выпустите TOTP в своей карточке либо попросите другого главного администратора выпустить его в вашей карточке.

Код одноразовый. Если не успели за 15 минут — выпустите новый той же командой.

### Нет доступа ни к панели, ни к паролю

Выполните обе команды: сначала `sudo mfagatectl admin <логин>` (новый пароль), затем `sudo mfagatectl emergency <логин>` (аварийный код).
