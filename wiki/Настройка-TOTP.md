# Настройка TOTP

TOTP — шестизначный код, который меняется каждые 30 секунд (RFC 6238). Работает без сети и с любым приложением-аутентификатором: MFA Gate Authenticator (вкладка «Коды»), а также сторонними для Android и iPhone.

Когда выдавать TOTP:

- сотруднику без Android-телефона (например, с iPhone);
- как запасной способ для тех, у кого есть телефон с push;
- для ресурсов, где шлюз не умеет долго ждать push (тогда в политике ресурса оставляют только метод TOTP).

## Как MFA Gate спрашивает код

- **По RADIUS** — через Access-Challenge: после пароля шлюз показывает окно «Введите одноразовый код». Так происходит, если у пользователя нет привязанного телефона или политика ресурса разрешает только `totp`. У пользователя с телефоном по RADIUS всегда идёт push, даже если ему выдан TOTP.
- **В панели** — для администраторов на шаге второго фактора.
- **Через REST API** — приложение передаёт код в поле `otp`.

Шлюз должен поддерживать Access-Challenge. Где это известно, отмечено в [Подключение VPN](Подключение-VPN.md).

## Шаг 1. Выпустите TOTP

«Пользователи» → карточка сотрудника → блок «TOTP» → «Выпустить».

**Ожидаемый результат:** окно «Выпуск TOTP» с QR-кодом и секретом для ручного ввода.

## Шаг 2. Добавьте код в приложение

- MFA Gate Authenticator: вкладка «Коды» → добавить → отсканировать QR-код.
- Другое приложение: «Добавить учётную запись» → «Сканировать QR-код» или ввести секрет вручную (тип — по времени).

**Ожидаемый результат:** в приложении появилась запись с названием сервера и логином, код меняется каждые 30 секунд.

## Шаг 3. Подтвердите

Введите в окне «Выпуск TOTP» текущий код из приложения в поле «Код из приложения», при желании задайте «Название» (например, «Телефон Иванова») и нажмите «Подтвердить».

**Ожидаемый результат:** «TOTP подключён», в карточке TOTP со статусом «Подключён».

Пока TOTP не подтверждён, он не работает. Если код не подходит («Код не подошёл — проверьте время на телефоне») — включите на телефоне «Дата и время сети» и попробуйте следующий код.

Если сотрудник не рядом, можно закрыть окно без подтверждения, а потом удалить неподтверждённый TOTP и выпустить новый в его присутствии. Секрет не пересылайте по почте и в мессенджерах.

## Шаг 4. Проверка

1. Временно оставьте у тестового пользователя только TOTP (без телефона) или создайте политику для тестового ресурса с методом только «TOTP-код».
2. Войдите в VPN: после пароля шлюз попросит код.
3. Введите текущий код.

**Ожидаемый результат:** VPN подключён; в «Истории входов» метод `totp`, статус «подтверждено». Повторный ввод того же кода отклоняется (`invalid_otp`) — это защита от повторного использования, дождитесь следующего кода.

Время на ввод кода после запроса — 120 секунд (`MFA_GATE_OTP_CHALLENGE_TIMEOUT`).

## TOTP для администратора панели

Первый TOTP администратор подключает сам при первом входе (экран «Подключите второй фактор»). Дополнительный или замену выпускает главный администратор в карточке администратора так же, как для сотрудника. Если администратор потерял все факторы — [Создание администратора](Создание-администратора.md), раздел «Потерян второй фактор».

## Удаление

Карточка → TOTP → «Удалить». Коды из этого приложения сразу перестают приниматься.
