# Приложение MFA Gate Authenticator

*Для кого: сотрудник с Android-телефоном; поддержка, которая помогает с установкой и настройкой приложения.*

MFA Gate Authenticator — приложение для Android, которое подтверждает вход в VPN и рабочие системы и показывает одноразовые коды. На этой странице описано, какой файл выбрать, как установить и обновить приложение, какие разрешения ему нужны и как сделать, чтобы запросы приходили сразу.

## Что умеет приложение

- **Подтверждать вход.** Запрос показывает учётную запись, ресурс, IP-адрес, клиент, время и обратный отсчёт. Кнопки **Подтвердить** и **Отклонить** срабатывают только после отпечатка пальца или PIN телефона.
- **Показывать одноразовые коды** без интернета: для MFA Gate и для любого другого сервиса, который поддерживает коды TOTP.
- **Работать с несколькими серверами**, например если организаций несколько.
- **Показывать историю** запросов по каждому серверу.

Приложения для iPhone нет. На iPhone используйте коды в любом приложении-аутентификаторе: [Как подключить приложение с кодами](Как-подключить-приложение-с-кодами.md).

Приложение пока не проверялось на реальных телефонах. Если что-то работает не так, как описано, сообщите администратору модель телефона и версию приложения: она указана во вкладке **Настройки**, в разделе **О приложении**.

## Что потребуется

- Android 8.0 или новее.
- Блокировка экрана: PIN, графический ключ, пароль или отпечаток пальца. Без неё приложение не создаст ключ подтверждения.
- На Android 8–10 — сканер отпечатков: на этих версиях вход подтверждается только отпечатком. PIN подходит начиная с Android 11.
- Интернет на телефоне для подтверждения входа. Для кодов интернет не нужен.

## Какой файл выбрать

Приложение выпускается в двух сборках. Возможности у них одинаковые, отличается только доставка запросов, когда приложение закрыто.

| Сборка | Файл | Для каких телефонов | Как приходят запросы |
| --- | --- | --- | --- |
| `gms` | `mfa-gate-authenticator-…-gms.apk` | с сервисами Google | через Firebase Cloud Messaging, если администратор его настроил |
| `foss` | `mfa-gate-authenticator-…-foss.apk` | любые, в том числе без сервисов Google, например Huawei | через собственное соединение приложения с сервером |

Берите сборку, которую назвал администратор. Если он ничего не сказал, берите `foss`: она работает на любом телефоне и не зависит от Google.

В обеих сборках есть запасной путь: раз в 15 минут приложение само проверяет, нет ли новых запросов. Пока приложение открыто, запросы появляются сразу.

## Как установить

1. Откройте главную личного кабинета: под формой входа есть блок **Приложение для телефона** с файлами той же версии, что и сервер. На компьютере наведите камеру телефона на QR-код, на телефоне нажмите **Скачать APK**. Те же файлы и контрольные суммы `SHA256SUMS` — на [странице выпусков](https://github.com/calleograph/mfa-gate/releases).
2. Откройте файл на телефоне.
3. Если Android спросит, разрешите установку приложений из этого источника, например из браузера или файлового менеджера.
4. Нажмите **Установить**.

**Что увидите:** значок **MFA Gate** на синем фоне. При первом запуске откроется экран **MFA Gate Authenticator** с кнопкой **Сканировать QR-код** и двумя текстовыми кнопками ниже: **Вставить ссылку вручную** и **Пропустить: только одноразовые коды**.

Дальше привяжите телефон к серверу: [Как подключить телефон](Как-подключить-телефон.md). Если телефон нужен только для кодов, нажмите **Пропустить: только одноразовые коды**.

## Разрешения

| Разрешение | Зачем | Что будет без него |
| --- | --- | --- |
| Камера | сканировать QR-код привязки и QR-коды для кодов | придётся вводить ссылку или секрет вручную |
| Уведомления | показывать **Запрос на вход** | о запросе вы узнаете, только открыв приложение |
| Отпечаток пальца или PIN | подписывать каждое решение | подтвердить или отклонить вход нельзя |

Приложение не просит доступ к контактам, файлам и местоположению.

Если уведомления выключены, на экране **Запросы входа** появится плашка **Уведомления выключены** с кнопкой **Разрешить уведомления** или **Открыть настройки уведомлений**.

## Как приходят запросы

Когда кто-то входит под вашей учётной записью, приходит уведомление **Запрос на вход** с кнопкой **Открыть запрос**. В самом уведомлении подробностей нет, а на заблокированном экране оно показывается в краткой форме. Подтвердить вход прямо из уведомления нельзя: решение принимается только на экране запроса, после отпечатка или PIN.

Если к одной учётной записи привязано несколько телефонов, запрос приходит на все. Ответить достаточно на одном.

### Сборка foss: постоянное соединение

В сборке `foss` приложение держит соединение с сервером, чтобы показывать запросы сразу, даже когда оно закрыто.

- Настройка: вкладка **Настройки** → раздел **Уведомления** → **Мгновенные уведомления**. По умолчанию включена.
- Пока соединение работает, в шторке висит тихое уведомление **Ожидание запросов входа**. Убирать его не нужно: по нему видно, что приложение на связи.
- Если выключить **Мгновенные уведомления**, запрос в фоне придёт с задержкой до 15 минут.

### Экономия заряда

Android и некоторые прошивки усыпляют приложения, чтобы экономить батарею. Тогда соединение обрывается, и запросы приходят с опозданием.

1. Откройте вкладку **Настройки**.
2. Нажмите **Экономия заряда**.
3. Найдите MFA Gate в списке. Иногда сначала нужно выбрать «Все приложения».
4. Отключите для MFA Gate оптимизацию батареи.

Кнопка **Экономия заряда** есть в сборке `foss`. В сборке `gms` уведомления доставляет Google, но если приложение принудительно остановить в настройках Android, они не придут, пока вы снова не откроете приложение.

## Экраны приложения

Внизу четыре вкладки:

| Вкладка | Что там |
| --- | --- |
| **Запросы** | экран **Запросы входа**: запросы, ожидающие решения, с обратным отсчётом. Обновляется сам |
| **Коды** | одноразовые коды. Нажатие на код копирует его, значок «+» добавляет новый |
| **Серверы** | привязанные серверы с кнопками **История** и **Отвязать**, кнопка **Привязать ещё сервер** |
| **Настройки** | **Блокировка приложения**, уведомления, **Экономия заряда**, версия приложения |

**Блокировка приложения** — вкладка **Настройки** → раздел **Безопасность**. Если включить, приложение спрашивает отпечаток или PIN при открытии и после 30 с в фоне. Подтверждение входа требует отпечатка или PIN всегда, независимо от этой настройки.

Экраны с кодами скрыты от снимков и записи экрана: на скриншоте они будут чёрными.

## Как обновить

1. Скачайте новый файл той же сборки, что у вас стоит: `gms` или `foss`.
2. Откройте его и нажмите **Обновить**.

Обновление ставится поверх, привязка и коды сохраняются. Перед обновлением приложение удалять не нужно: при удалении пропадают ключи, и телефон придётся привязывать заново.

Если Android отказывается ставить обновление поверх и сообщает о конфликте, значит новый файл подписан другим ключом. Так бывает с предварительными выпусками. Тогда сначала убедитесь, что можете войти в кабинет кодом из приложения или резервным кодом. Затем удалите старое приложение, установите новое и привяжите телефон заново: [Если телефон потерян или заменён](Если-телефон-потерян-или-заменён.md#телефон-тот-же-но-привязка-пропала).

## Как отвязать телефон от сервера

1. Откройте вкладку **Серверы**.
2. Нажмите **Отвязать** у нужного сервера.
3. Подтвердите кнопкой **Отвязать**.

**Что увидите:** сервер исчезнет из списка. Телефон перестанет получать запросы входа, ключ устройства будет удалён. Чтобы вернуть привязку, понадобится новый QR-код.

Если сервер не отвечает, приложение предложит **Удалить на телефоне**. Тогда привязка удалится только с телефона, а на сервере останется, пока её не отвяжете вы в личном кабинете или администратор.

Если администратор отозвал телефон, при следующей связи приложение сообщит: **Устройство отвязано на сервере. Учётная запись удалена с телефона.**

## Если не получается

| Что видно | Почему | Что сделать |
| --- | --- | --- |
| **Нет связи с сервером. Проверьте сеть и нажмите «Повторить».** | нет интернета или сервер недоступен | включите интернет, нажмите **Повторить**; если не помогает, сообщите администратору |
| Запросы приходят с опозданием | система усыпляет приложение | отключите оптимизацию батареи, проверьте **Мгновенные уведомления** в `foss` |
| **Уведомления выключены** | уведомления запрещены | нажмите **Разрешить уведомления** или **Открыть настройки уведомлений** |
| **Ключ устройства стал недействителен (изменились отпечатки или блокировка экрана). Отвяжите сервер и привяжите заново.** | после смены отпечатков ключ перестаёт работать — так устроена защита Android | отвяжите сервер и привяжите телефон заново через кабинет |
| **Добавьте отпечаток пальца в настройках телефона: без него подтверждать входы нельзя.** | на Android 8–10 вход подтверждается только отпечатком | добавьте отпечаток в настройках телефона; если сканера нет, подключите приложение с кодами |
| **Проверка отменена.** | вы закрыли окно отпечатка | нажмите кнопку решения ещё раз |
| **Запрос уже обработан: решение по нему принято раньше.** | вы ответили на другом телефоне или повторно | ничего делать не нужно |
| Код из вкладки **Коды** не подходит | время на телефоне неточное | включите автоматическое время по сети |

Подробнее для поддержки: [Решение проблем телефона и push](Решение-проблем-телефона-и-push.md).
