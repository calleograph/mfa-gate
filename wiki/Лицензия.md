# Лицензия

*Для кого: руководитель, юрист, администратор, разработчик, который хочет использовать или дорабатывать MFA Gate.*

MFA Gate распространяется по лицензии Apache License 2.0. Здесь простыми словами объяснено, что она разрешает и чего требует. Отдельно перечислены сторонние компоненты, которые лежат в репозитории со своими лицензиями. Эта страница не заменяет текст лицензии: юридическую силу имеет файл [LICENSE](https://github.com/calleograph/mfa-gate/blob/main/LICENSE).

## Что разрешает Apache-2.0

| Можно | Условия |
| --- | --- |
| Использовать MFA Gate в любой организации, в том числе коммерческой, без оплаты | — |
| Изменять исходный код под свои задачи | В изменённых файлах нужно отметить, что они изменены |
| Распространять MFA Gate и его изменённые версии, в том числе в составе своих продуктов и за плату | Приложить текст лицензии и сохранить файл `NOTICE`, уведомления об авторских правах и лицензиях |
| Использовать патенты участников, которые относятся к их вкладу | Право прекращается для того, кто подаёт патентный иск, утверждая, что MFA Gate нарушает его патент |

Чего лицензия не даёт:

- права на название и знаки MFA Gate: изменённую версию нельзя выдавать за оригинал;
- гарантий и ответственности авторов: продукт предоставляется «как есть».

Свой код, который только обращается к MFA Gate по RADIUS, REST API или Device API, не становится производной работой и может распространяться на любых условиях.

## Файл NOTICE

В корне репозитория лежит [NOTICE](https://github.com/calleograph/mfa-gate/blob/main/NOTICE). В нём сказано, что продукт распространяется по Apache-2.0 и правами владеют авторы проекта MFA Gate, а также перечислены сторонние компоненты, которые входят в репозиторий. При распространении MFA Gate или его изменённой версии файл `NOTICE` нужно сохранить.

## Сторонние компоненты в репозитории

| Компонент | Где лежит | Лицензия | Текст лицензии |
| --- | --- | --- | --- |
| Шрифты Inter, Manrope, JetBrains Mono | `server/web/assets/fonts/` | SIL Open Font License 1.1 (OFL) | `server/web/assets/fonts/OFL.txt` |
| Иконки Lucide | `server/web/assets/icons/` | ISC | `server/web/assets/icons/LICENSE-lucide.txt` |

Шрифты по OFL можно использовать и распространять вместе с программой, но нельзя продавать отдельно. Иконки по ISC можно использовать свободно при сохранении уведомления.

## Зависимости

Зависимости устанавливаются при сборке и в репозиторий не входят. Их лицензии совместимы с Apache-2.0:

| Часть | Лицензии зависимостей |
| --- | --- |
| Сервер (FastAPI, SQLAlchemy, Alembic, cryptography, argon2-cffi, httpx и другие) | MIT, BSD, Apache-2.0 |
| Библиотека ldap3 | LGPL-3.0. Используется как библиотека без изменений, это совместимо с Apache-2.0 |
| PostgreSQL (образ `postgres:16-alpine`) | PostgreSQL License |
| Приложение Android (AndroidX, Compose, OkHttp, ZXing и другие) | Apache-2.0 |
| Firebase SDK | Входит только в сборку gms; в сборке foss кода Google нет |

Полный перечень лицензий зависимостей в репозитории не сведён: при необходимости соберите его средствами сборки (`pip-licenses`, отчёты Gradle).
