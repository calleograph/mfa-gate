# Удаление и повторная установка

## Удалить контейнеры, сохранив данные

```bash
sudo mfagatectl uninstall
```

**Ожидаемый результат:** `контейнеры удалены; данные сохранены в /opt/mfa-gate/deploy/data и /opt/mfa-gate/deploy/backups — повторный ./mfagatectl install вернёт систему`.

Что остаётся: база, мастер-ключ, резервные копии, `deploy/.env`, образы Docker, журналы установки.

**Как проверить:** `sudo docker ps --filter label=com.docker.compose.project=mfa-gate` — пустой список; `sudo ls /opt/mfa-gate/deploy/data` — каталоги `postgres` и `secrets` на месте.

## Повторная установка

```bash
cd /opt/mfa-gate && sudo ./install.sh
```

Повторный запуск сохраняет `.env`, мастер-ключ и данные: пользователи, телефоны, настройки возвращаются как были. Пароль существующего администратора не меняется («главный администратор уже существует»).

**Ожидаемый результат:** «Готово», `sudo mfagatectl status` — все сервисы `healthy`, вход в панель с прежним паролем.

Тот же способ подходит, чтобы «починить» установку: вернуть контейнеры после ручных изменений, пересоздать команду `mfagatectl`.

## Удалить вместе с данными

**Необратимо.** Сначала сделайте копию, если данные могут понадобиться: `sudo mfagatectl backup` и перенесите её вместе с мастер-ключом с сервера.

```bash
sudo mfagatectl uninstall --purge
```

Команда спросит подтверждение: введите `DELETE` заглавными буквами.

**Ожидаемый результат:** `MFA Gate удалён вместе с данными`. Удалены контейнеры, база, мастер-ключ, все резервные копии в `deploy/backups` и `deploy/.env`.

Что `--purge` **не** удаляет — удалите вручную, если нужно:

```bash
sudo rm -f /usr/local/bin/mfagatectl                    # команда управления
sudo docker image ls | grep -E 'mfa-gate|postgres'       # образы: удалить через sudo docker image rm <ID>
sudo rm -rf /var/log/mfa-gate                            # журналы установщика
sudo rm -f /etc/cron.d/mfa-gate-backup                   # расписание копий (если настраивали cron)
sudo systemctl disable --now mfa-gate-backup.timer 2>/dev/null; sudo rm -f /etc/systemd/system/mfa-gate-backup.*
sudo rm -f /opt/mfa-gate/deploy/compose.override.yml    # если настраивали FCM
sudo rm -rf /opt/mfa-gate                                # сам каталог установки
```

Также удалите правила межсетевого экрана для портов 1812 и 8080 (`sudo iptables -L DOCKER-USER -n --line-numbers`, затем `sudo iptables -D DOCKER-USER <номер>` и `sudo netfilter-persistent save`), конфигурацию reverse proxy и RADIUS-сервер в настройках VPN-шлюзов. Docker установщик не удаляет.

**Как проверить:** `sudo docker ps -a | grep mfa-gate` — пусто; `ls /opt/mfa-gate` — `No such file or directory`.

## Чистая установка заново

После `--purge` каталог `deploy` пуст от данных, и `sudo ./install.sh` выполняет установку с нуля: новый мастер-ключ, новый пароль базы, новый администратор `admin` с временным паролем. Телефоны, привязанные к прежней установке, нужно привязать заново, а секреты RADIUS-клиентов — заново указать на шлюзах.
