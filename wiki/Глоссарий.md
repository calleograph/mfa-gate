# Глоссарий

*Для кого: все читатели вики.*

Термины, которые встречаются в вики и в интерфейсе MFA Gate, с короткими объяснениями. Термины расположены по алфавиту: сначала русские, затем латинские.

## Русские термины

| Термин | Что значит |
| --- | --- |
| Аварийный код | Одноразовый код, который администратор вводит вместо второго фактора при входе в панель, если потерял телефон и приложение с кодами. Выпускается только в консоли сервера командой `mfagatectl emergency`, действует 15 минут ([Аварийный доступ администратора](Аварийный-доступ-администратора.md)) |
| Блокировка (временная) | После 8 ошибок пароля или кода подряд учётная запись не может войти 15 минут. Снимается сама или кнопкой **Снять блокировку** |
| Внешний адрес для телефонов | Адрес из `MFA_GATE_DEVICE_URL`, по которому телефоны обращаются к серверу из Интернета, например `https://auth.example.org`. На нём доступен только Device API |
| Внутренний адрес | Адрес из `MFA_GATE_PUBLIC_URL`, по которому сотрудники и администраторы открывают личный кабинет и панель, например `https://mfa.example.org` |
| Второй фактор | Подтверждение после пароля: нажатие в приложении на телефоне, код из приложения с кодами или резервный код (только для кабинета) |
| Группа | Набор пользователей в MFA Gate. Группу можно связать с группой каталога, тогда членство берётся из AD или LDAP. Группы используются в политиках |
| Журнал аудита | Список событий безопасности: кто, что, когда и откуда сделал. Изменить или удалить запись из панели нельзя, старые записи удаляются через 365 дней ([Справочник: журнал аудита](Справочник-журнал-аудита.md)) |
| История входов | Список попыток входа сотрудников с итогом и причиной отказа |
| Каталог | Служба учётных записей организации: Active Directory или другой LDAP-сервер. MFA Gate проверяет в нём пароль и читает группы |
| Ключ API | Пара `key_id:secret` для обращения внешней системы к REST API. Получает только выданные права ([Ключи API](Ключи-API.md)) |
| Личный кабинет | Часть MFA Gate по адресу `/`, где сотрудник сам настраивает способы входа, получает резервные коды и смотрит свои входы |
| Мастер-ключ | Файл `data/secrets/master.key`, которым шифруются секреты в базе. В резервную копию не входит, его копию хранят отдельно |
| Общий секрет (shared secret) | Пароль, который знают RADIUS-клиент и MFA Gate. Им защищён пароль в запросе и подписаны пакеты |
| Панель | Часть MFA Gate по адресу `/admin/` для администраторов |
| Первичная настройка | Первое подключение способа входа сотрудником в личном кабинете по одному паролю. Разрешена только из сетей регистрации, для разрешённых групп и один раз ([Первичная настройка сотрудниками](Первичная-настройка-сотрудниками.md)) |
| Повторная настройка | Разрешение администратора на 24 часа заново настроить способ входа по одному паролю, например после потери телефона |
| Политика | Правило, которое для выбранных ресурсов и групп требует второй фактор, пропускает или запрещает вход ([Политики доступа](Политики-доступа.md)) |
| Привязка телефона | Подключение приложения MFA Gate Authenticator к учётной записи по одноразовому QR-коду |
| Резервные коды | 10 одноразовых кодов для входа в личный кабинет, если телефона нет под рукой. Для VPN не действуют ([Резервные коды](Резервные-коды.md)) |
| Ресурс | То, во что входит сотрудник: VPN, приложение. К ресурсу привязываются RADIUS-клиенты, ключи API и политики |
| Роль | Набор прав администратора в панели: главный администратор, администратор, оператор, аудитор ([Справочник: роли и права](Справочник-роли-и-права.md)) |
| Сам шлюз | Режим RADIUS-клиента, в котором доменный пароль проверяет VPN-шлюз, а MFA Gate отвечает только за второй фактор ([Шлюзы с собственной проверкой пароля](Шлюзы-с-собственной-проверкой-пароля.md)) |
| Сети регистрации | Сети из `MFA_GATE_PORTAL_ENROLL_NETWORKS`, из которых разрешена первичная настройка |
| Сквозные тесты | Автоматические проверки всего пути входа через настоящие службы: RADIUS, REST API, Device API, база |
| Способ входа | То же, что второй фактор у конкретного сотрудника: привязанный телефон или приложение с кодами |
| Шлюз (VPN-шлюз) | Устройство или служба, к которой подключается VPN-клиент сотрудника. Спрашивает MFA Gate по RADIUS |

## Латинские термины

| Термин | Что значит |
| --- | --- |
| Access-Accept, Access-Reject | Ответы RADIUS: вход разрешён или отклонён |
| Access-Challenge | Ответ RADIUS «введите код»: шлюз показывает сотруднику поле для кода и присылает его следующим запросом |
| Access-Request | Запрос шлюза к RADIUS-серверу с логином и паролем |
| Active Directory (AD) | Каталог учётных записей Microsoft |
| Android Keystore | Защищённое хранилище ключей Android. Закрытый ключ MFA Gate создаётся в нём и не извлекается |
| argon2id | Медленная функция хеширования паролей, затрудняет перебор |
| BlastRADIUS | Атака 2024 года на RADIUS с подделкой ответа. Защита — обязательный атрибут Message-Authenticator |
| Calling-Station-Id | Атрибут RADIUS с адресом сотрудника, с которого он подключается к VPN |
| CSRF | Подделка запроса от имени вошедшего пользователя. В панели от неё защищает токен в каждом изменяющем запросе |
| Device API | Программный интерфейс `/api/device/v1/` для приложения на телефоне: привязка, получение запросов, подписанные ответы |
| ECDSA P-256 | Алгоритм цифровой подписи. Им телефон подписывает каждое решение «подтвердить» или «отклонить» |
| FCM (Firebase Cloud Messaging) | Служба доставки push от Google. Используется сборкой приложения gms |
| foss, gms | Две сборки приложения: foss — без сервисов Google, gms — с доставкой через FCM |
| HMS | Служба доставки push Huawei. Поддержка экспериментальная |
| LDAP, LDAPS, STARTTLS | Протокол каталогов и два способа его шифрования: LDAPS (порт 636) и STARTTLS (порт 389) |
| Long-poll | Способ получать запросы без push: приложение держит запрос к серверу открытым, пока не придёт новый вход |
| Message-Authenticator | Атрибут RADIUS, подписывающий весь пакет общим секретом |
| MFA | Многофакторная аутентификация: вход по паролю и ещё одному подтверждению |
| NAS, NAS-Identifier | Устройство, которое отправляет RADIUS-запрос (обычно VPN-шлюз), и его имя в запросе |
| Number matching | Подтверждение вводом числа с экрана входа. В MFA Gate пока нет ([Планы развития](Планы-развития.md)) |
| objectGUID | Неизменный идентификатор объекта в Active Directory. По нему MFA Gate отличает разных людей с одинаковым логином |
| PAP | Способ передачи пароля в RADIUS, при котором сервер получает сам пароль и может проверить его в каталоге |
| Push | Уведомление на телефон о новом запросе входа. В MFA Gate это только сигнал, без подробностей |
| RADIUS | Протокол, по которому VPN-шлюз спрашивает MFA Gate, пускать ли пользователя. Порт UDP 1812 |
| RADIUS-клиент | VPN-шлюз или другой сервер, зарегистрированный в MFA Gate по адресу и общему секрету ([Настройка RADIUS](Настройка-RADIUS.md)) |
| RadSec | RADIUS поверх TLS. В MFA Gate не реализован |
| Reverse proxy | Веб-сервер (nginx, Caddy), который принимает HTTPS и передаёт запросы MFA Gate ([HTTPS через reverse proxy](HTTPS-через-reverse-proxy.md)) |
| REST API | Программный интерфейс `/api/v1/` для своих приложений и порталов ([Интеграция по REST API](Интеграция-по-REST-API.md)) |
| TOTP | Одноразовые коды из 6 цифр, которые меняются каждые 30 секунд (RFC 6238). Их показывает любое приложение-аутентификатор |
| UnifiedPush | Открытый способ доставки push через распределитель, который организация может развернуть сама. Поддержка экспериментальная |
| UPN | Логин вида `ivanov@example.org` в Active Directory |
