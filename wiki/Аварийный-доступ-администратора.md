# Аварийный доступ администратора

*Для кого: администратор сервера, у которого есть `sudo`, и главный администратор MFA Gate.*

Страница описывает, как вернуть вход в панель, если администратор забыл пароль, потерял телефон или и то и другое. Для этого на сервере есть две команды: `mfagatectl admin` задаёт новый пароль, `mfagatectl emergency` выдаёт одноразовый код вместо второго фактора. Оба действия записываются в журнал, поэтому каждый аварийный вход виден.

## Зачем это нужно

Вход в панель всегда требует пароля и второго фактора. Если что-то из этого утеряно, обычный путь закрыт. Сбросить второй фактор в панели может другой главный администратор, но если его нет или он тоже недоступен, остаётся сервер: кто управляет сервером, тот и восстанавливает доступ. Эти команды работают только из консоли сервера, через браузер их вызвать нельзя.

## Когда пригодится

- Забыт пароль локального администратора или потерян временный пароль после установки.
- Потерян телефон или удалено приложение с кодами, а другого главного администратора нет.
- Утеряно всё сразу.

Если второй главный администратор доступен, сначала попросите его: он может выпустить вам новый TOTP или отозвать телефон в вашей карточке. Это проще и не требует сервера.

## Что потребуется

- SSH-доступ к серверу MFA Gate и права `sudo`.
- Работающие контейнеры: `sudo mfagatectl status` показывает `api` в состоянии `healthy`.
- Интерактивный терминал. Команды `admin` и `emergency` выполняются внутри контейнера в режиме терминала; при запуске из скрипта или через `ssh` без терминала Docker сообщит `the input device is not a TTY`. Подключайтесь обычным `ssh` или `ssh -t`.

## Где найти

- Команды: `sudo mfagatectl admin <логин>` и `sudo mfagatectl emergency <логин>` на сервере.
- Ввод аварийного кода: экран входа в панель → **Подтвердите вход** → поле **Код из приложения** (если подключён TOTP) или кнопка **Ввести аварийный код** → поле **Аварийный код** (если TOTP нет).
- События: **Панель → Журнал**, записи **Выпущен аварийный код** и **Аварийный вход в панель**.

## Как это сделать

### Забыт пароль

```bash
sudo mfagatectl admin admin
```

Вместо второго `admin` укажите нужный логин.

**Что увидите:**

```text
главный администратор admin создан
пароль (показывается один раз): …
при первом входе в панель будет предложено подключить TOTP
```

Слово «создан» печатается и при сбросе пароля существующей учётной записи. Команда задаёт новый случайный пароль, снимает блокировку и оставляет второй фактор как был. Последняя строка выводится всегда: если TOTP уже подключён, панель просто спросит код.

Войдите с новым паролем и смените его через меню профиля → **Сменить пароль**. Остальные сеансы этой учётной записи при смене завершатся.

Будьте внимательны с логином: если такой локальной учётной записи нет, команда создаст нового главного администратора, а если есть обычный локальный пользователь с этим логином — сделает его главным администратором.

Для администратора из каталога команда не подходит и отвечает `пользователь из каталога: назначьте роль в панели, пароль меняется в каталоге`. Пароль такого администратора сбрасывают в Active Directory.

### Потерян второй фактор

1. Выпустите аварийный код:

   ```bash
   sudo mfagatectl emergency admin
   ```

   **Что увидите:**

   ```text
   одноразовый аварийный код для admin (действует 15 мин, заменяет второй фактор один раз):
   3f9a1c-7b20de-c41f08
   ```

   Код ваш будет другим: три группы по шесть символов. Если логин не принадлежит администратору, команда ответит `администратор не найден`.

2. Откройте панель, введите логин и **пароль**: аварийный код заменяет только второй фактор.
3. На экране **Подтвердите вход** введите аварийный код и нажмите **Войти**. Где его вводить, зависит от того, подключён ли у вас TOTP:
   - **TOTP подключён** — в поле **Код из приложения**. Подсказка под полем напоминает: «Аварийный код, выданный на сервере, тоже подходит». Если панель сразу отправила запрос на телефон, сначала нажмите **Ввести код вместо этого**.
   - **TOTP нет, только телефон** — панель отправит запрос на потерянный телефон. Не ждите его: нажмите **Ввести аварийный код** и введите код в поле **Аварийный код** в виде `xxxxxx-xxxxxx-xxxxxx`.

4. Сразу подключите новый фактор. Откройте **Панель → Пользователи**, найдите свою карточку:
   - в блоке **TOTP** удалите старую запись кнопкой **Удалить** и нажмите **Выпустить**, отсканируйте QR-код, введите код и нажмите **Подтвердить**;
   - в блоке **Телефоны** отзовите потерянный телефон кнопкой **Отозвать**; новый привяжите кнопкой **Привязать телефон**.

**Что увидите:** в **Панель → Журнал** события **Выпущен аварийный код** и **Аварийный вход в панель** с критическим уровнем. Так и должно быть.

Код одноразовый и действует 15 минут. Не успели — выпустите новый той же командой.

Экран **Подключите второй фактор** после пароля больше не появится: он показывается, только если у учётной записи нет TOTP и никогда не было привязанного телефона, даже отозванного. Это защита от подмены фактора тем, кто узнал пароль.

### Утеряно всё

Выполните обе команды по очереди, затем войдите с новым паролем и аварийным кодом:

```bash
sudo mfagatectl admin admin
sudo mfagatectl emergency admin
```

### Учётная запись заблокирована

После 8 ошибок пароля или кода подряд вход блокируется на 15 минут. На шаге пароля панель отвечает общей фразой «Неверный логин или пароль, либо учётная запись временно заблокирована.», на шаге кода — «Слишком много ошибок, вход временно заблокирован». Аварийный код во время блокировки не принимается. Подождите 15 минут или попросите другого администратора нажать **Снять блокировку** в вашей карточке. Команда `mfagatectl admin` тоже снимает блокировку, но заодно меняет пароль.

## Что получится

- Администратор снова входит в панель.
- Старый фактор отозван, новый подключён.
- В журнале остались записи **Администратор создан в консоли**, **Выпущен аварийный код**, **Аварийный вход в панель** с указанием логина и времени.

Проверьте журнал после любого аварийного входа. Если вы не выпускали код, а событие есть, кто-то получил доступ к серверу: смените пароли администраторов и разберитесь с доступом по SSH.

## Если не получается

| Что видно | Почему | Что сделать |
|---|---|---|
| `the input device is not a TTY` | команда запущена без терминала | подключитесь `ssh -t` и повторите |
| `администратор не найден` | у учётной записи нет роли или опечатка в логине | проверьте логин; при необходимости `sudo mfagatectl admin <логин>` |
| «Неверный или уже использованный код» | код истёк, уже использован или введён с ошибкой | выпустите новый код |
| «Слишком много ошибок, вход временно заблокирован» | 8 ошибок подряд | подождите 15 минут |
| «Второй фактор уже подключался — войдите с ним; если телефон утерян, нужен аварийный код (mfagatectl emergency) или главный администратор» | вы пытаетесь заново пройти первичную настройку | войдите по аварийному коду и выпустите TOTP в своей карточке |
| `service "api" is not running` или похожая ошибка Docker | контейнеры остановлены | `sudo mfagatectl start` |
