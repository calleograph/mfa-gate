# Маршрут сетевого администратора

*Для кого: сетевой инженер, который готовит сеть для MFA Gate и подключает VPN-шлюзы.*

## Кому подходит

Этот маршрут для вас, если вы отвечаете за межсетевой экран, reverse proxy, DNS, сертификаты и VPN-шлюзы. Установку сервера и настройку каталога обычно делает администратор MFA Gate: его маршрут — [Маршрут администратора](Маршрут-администратора.md). От вас нужны три вещи: RADIUS между шлюзом и сервером, внешний адрес для телефонов и закрытые внутренние адреса.

## Что важно знать заранее

- **Таймаут RADIUS на шлюзе — не меньше 60 с.** MFA Gate держит запрос открытым, пока сотрудник отвечает на телефоне, до 45 с. Многие шлюзы по умолчанию ждут несколько секунд.
- **Только PAP и Message-Authenticator.** CHAP, MS-CHAPv2 и EAP не поддерживаются; пакеты без Message-Authenticator отбрасываются.
- **Телефонам нужен доступ из интернета.** Сотрудник подтверждает вход до подключения VPN, поэтому наружу публикуется только префикс `/api/device/` на отдельном имени. Кабинет, панель и REST API остаются внутри.
- **Порты Docker обходят `ufw`.** Фильтруйте их в цепочке `DOCKER-USER`.
- **На настоящих шлюзах профили не проверялись.** Протокол покрыт сквозными тестами, но пробный вход на вашем шлюзе обязателен.

## Что вы будете уметь

- Открыть RADIUS только для VPN-шлюзов и защитить его между площадками.
- Опубликовать Device API наружу так, чтобы панель и кабинет остались внутри.
- Настроить reverse proxy с правильными заголовками и таймаутами.
- Подключить шлюз с проверкой пароля в MFA Gate или в самом шлюзе.
- Проверить по истории входов и журналу, что шлюз работает как ожидается.
