# Быстрая установка All-in-One

All-in-One — все компоненты MFA Gate на одном сервере: PostgreSQL, RADIUS, веб-панель, фоновый обработчик. Установка занимает 5–10 минут.

Перед началом проверьте [Требования к серверу](Требования-к-серверу.md).

## Шаг 1. Установка

```bash
sudo apt-get update && sudo apt-get install -y git
cd /opt
sudo git clone https://github.com/calleograph/mfa-gate.git && cd mfa-gate && sudo ./install.sh
```

Установщик проходит этапы и печатает каждый на экране:

| Этап на экране | Что происходит |
|---|---|
| Проверка сервера | ОС (Ubuntu/Debian), архитектура, память ≥ 1 ГБ, диск ≥ 5 ГБ, доступ к `ghcr.io` или `github.com` |
| Docker и необходимые пакеты | ставит `curl`, `openssl`, `iproute2`, при необходимости Docker и Docker Compose v2, включает службу Docker |
| Конфигурация | создаёт `deploy/.env` (права 600): определяет IP сервера, выбирает свободный HTTP-порт (8080…8100), проверяет UDP 1812, генерирует пароль базы. Если `.env` уже есть, он сохраняется |
| Образы, база данных и запуск | генерирует мастер-ключ `deploy/data/secrets/master.key`, загружает образ (если реестр недоступен — собирает его из исходников), применяет миграции, запускает сервисы и ждёт, пока они станут healthy (до 3 минут) |
| Первый администратор | создаёт администратора `admin` с временным паролем, если администратора ещё нет |
| Проверка работы | проверяет `/health/ready`, открытие панели, что RADIUS слушает порт; создаёт команду `mfagatectl` |

Подробный журнал пишется в `/var/log/mfa-gate/install-<дата>-<время>.log`. Пароль администратора в журнал не попадает.

**Ожидаемый результат:** в конце — блок «Готово»:

```text
Готово. MFA Gate 0.2.0 установлен.

  Панель администратора:  http://192.0.2.10:8080
  Логин:                  admin
  Временный пароль:       Xy7…(18 случайных символов)
                          (показан один раз; при первом входе его нужно сменить, затем подключить второй фактор)
  RADIUS для VPN-шлюзов:  UDP-порт 1812 на адресе этого сервера
  Данные и мастер-ключ:   /opt/mfa-gate/deploy/data   (сохраните копию data/secrets/master.key отдельно!)
```

**Сразу перепишите временный пароль.** Он показывается один раз. Если вы его потеряли — см. [Создание администратора](Создание-администратора.md), раздел «Восстановление доступа».

**Если установщик остановился:** он печатает `ОШИБКА на этапе «…»`, причину и строку «Как исправить», а также путь к журналу. Типовые случаи — на странице [Диагностика](Диагностика.md), раздел «Установка».

## Шаг 2. Проверка

```bash
sudo mfagatectl status
```

**Ожидаемый результат:** сервисы `api`, `radius`, `worker`, `postgres` в состоянии `Up … (healthy)`, внизу `версия: 0.2.0`.

```bash
curl -fsS http://127.0.0.1:8080/health/ready; echo
```

**Ожидаемый результат:** ответ JSON со `"status":"ok"`. Если установщик выбрал другой порт, подставьте его (он указан в строке «Панель администратора»).

Откройте в браузере панель: адрес из итогового блока с `/admin/` на конце, например `http://192.0.2.10:8080/admin/`. **Ожидаемый результат:** страница входа MFA Gate. По адресу без `/admin/` открывается личный кабинет сотрудника.

## Шаг 3. Сохраните мастер-ключ

Без мастер-ключа резервные копии бесполезны. Скопируйте его с сервера в надёжное место (менеджер паролей, сейф) — отдельно от резервных копий:

```bash
sudo cat /opt/mfa-gate/deploy/data/secrets/master.key
```

**Ожидаемый результат:** одна строка base64 длиной 44 символа. Сохраните её целиком. Подробнее: [Резервное копирование](Резервное-копирование.md).

## Нестандартные порты и адрес

Значения можно задать при первой установке через переменные окружения. Они записываются в `deploy/.env` и дальше берутся оттуда.

| Переменная | По умолчанию | Когда менять |
|---|---|---|
| `MFA_GATE_HTTP_PORT` | 8080 (или первый свободный до 8100) | порт занят или нужен конкретный |
| `MFA_GATE_RADIUS_PORT` | 1812 | на сервере уже работает другой RADIUS-сервер |
| `MFA_GATE_PUBLIC_URL` | `http://<IP сервера>:<порт>` | у сервера есть DNS-имя или установщик определил не тот IP |
| `COMPOSE_PROJECT_NAME` | `mfa-gate` | на хосте второй экземпляр MFA Gate |

Пример:

```bash
cd /opt/mfa-gate
sudo MFA_GATE_HTTP_PORT=8180 MFA_GATE_RADIUS_PORT=11812 MFA_GATE_PUBLIC_URL=http://mfa.example.org:8180 ./install.sh
```

**Ожидаемый результат:** в итоговом блоке — заданные порт и адрес.

**Как проверить:** `sudo grep -E '^MFA_GATE_(HTTP_PORT|RADIUS_PORT|PUBLIC_URL)=' /opt/mfa-gate/deploy/.env`.

Если `.env` уже создан, переменные окружения при повторном запуске **не применяются**. Измените значения в `deploy/.env` и выполните `sudo mfagatectl start` — контейнеры пересоздадутся с новыми настройками.

Нестандартный порт RADIUS нужно указать и на VPN-шлюзе.

## Повторный запуск установщика

`sudo ./install.sh` можно запускать повторно: он сохраняет `.env`, мастер-ключ и данные, не меняет пароль существующего администратора и доводит контейнеры до состояния конфигурации. Это безопасный способ «починить» установку после ручных изменений.
