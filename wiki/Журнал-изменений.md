# Журнал изменений

*Для кого: администратор, который обновляет MFA Gate, и все, кому интересно, что нового.*

Здесь коротко пересказано, что менялось в каждой версии и на что обратить внимание при обновлении. Полный журнал для разработчиков — [CHANGELOG.md](https://github.com/calleograph/mfa-gate/blob/main/CHANGELOG.md), файлы выпусков (образ сервера и APK приложения) — на странице [Выпуски](https://github.com/calleograph/mfa-gate/releases). Как обновиться — [Обновление](Обновление.md).

Номера версий следуют правилам семантического версионирования. Сервер и приложение Android выпускаются вместе и имеют один номер.

## 0.3.1 — 19 ноября 2026

Постоянная подпись приложения Android.

- Приложение MFA Gate Authenticator подписано постоянным ключом. Следующие версии будут устанавливаться поверх, выпуск больше не помечен как предварительный.
- **Важно при обновлении:** тестовые APK версии 0.3.0 поверх не обновляются. Удалите приложение, установите 0.3.1 и заново привяжите телефон.
- Привязывать телефоны можно чаще: до 30 раз в минуту с одного адреса. В день внедрения телефоны офиса выходят в интернет через один адрес, и прежнего предела не хватало.
- Переписано описание проекта в репозитории.

## 0.3.0 — 19 ноября 2026

Личный кабинет сотрудника, внешний адрес для телефонов, режим для шлюзов, которые сами проверяют доменный пароль.

**Новое:**

- **Личный кабинет** по адресу `/`. Сотрудник входит доменной учётной записью, сам настраивает второй фактор (по умолчанию приложение с кодами, телефон с MFA Gate — если разрешает политика), получает 10 резервных кодов, видит свои способы входа, историю входов и сеансы. Последний способ входа удалить нельзя.
- **Защита первичной настройки.** Сотрудник может настроить способ входа по одному паролю только из сетей `MFA_GATE_PORTAL_ENROLL_NETWORKS` (по умолчанию частные сети), только если входит в группы `MFA_GATE_PORTAL_ENROLL_GROUPS` и только если способа входа у него ещё не было. После потери телефона администратор нажимает **Разрешить повторную настройку** — разрешение действует 24 часа. Администратор может сбросить резервные коды.
- **Внешний адрес для телефонов** `MFA_GATE_DEVICE_URL`. Он попадает в QR-код привязки, и телефон подтверждает вход в VPN из дома. На этом адресе сервер отвечает только на запросы приложения.
- **Режим для шлюзов, которые сами проверяют доменный пароль.** У RADIUS-клиента появилось поле **Кто проверяет доменный пароль**: MFA Gate или сам шлюз. Во втором режиме пустой пароль ведёт к подтверждению на телефоне или запросу кода, а 6–8 цифр считаются кодом TOTP.
- Экран **Адреса и публикация**: компоненты, адреса, направления, кому разрешён доступ, готовые настройки nginx и Caddy. Диагностика проверяет внешний адрес для телефонов.
- Приложение Android (сборка foss): уведомления приходят и при закрытом приложении через постоянное соединение, приложение запускается после перезагрузки и обновления, есть кнопка настроек экономии заряда.

**Изменено:**

- Панель управления переехала на `/admin/`. Старые закладки вида `/#/…` перенаправляются.
- Поиск пользователя без пароля (REST API и режим шлюза) понимает формы `DOMAIN\user` и UPN.

**Исправлено:**

- Телефон мог узнать о новом запросе входа с опозданием до 25 секунд; теперь задержка не больше 2 секунд.

## 0.2.0 — 19 ноября 2026

Установка одной командой.

**Новое:**

- Установка All-in-One: `sudo ./install.sh` на Ubuntu или Debian проверяет сервер, ставит Docker, создаёт настройки, выбирает свободные порты, запускает систему и создаёт первого администратора.
- Первый администратор получает временный пароль и обязан сменить его при первом входе. Свой пароль можно сменить в панели.
- Панель работает по HTTP для первичной настройки (`http://IP:8080`). За reverse proxy с HTTPS cookie автоматически получают флаг `Secure`.
- Интеграция с OpenVPN без RADIUS: скрипт `integrations/openvpn/mfa-gate-openvpn.sh`.
- Команды `mfagatectl admin-init` и `mfagatectl uninstall`. Если реестр образов недоступен, образ собирается из исходников.
- Нагрузочный тест RADIUS.
- Приложение Android MFA Gate Authenticator в новом оформлении; подключение к серверу по HTTP — только после явного подтверждения.

**Изменено:**

- Единое название во всех частях: переменные `MFA_GATE_*`, команда `mfagatectl`, образ `ghcr.io/calleograph/mfa-gate`, схема привязки `mfagate://`.
- Предел попыток входа хранится в базе и общий для всех экземпляров `api`.
- Новое оформление панели.

**Удалено:**

- Прежняя реализация продукта заменена новой. Данные старых установок автоматически не переносятся.

## 0.1.0 — 18 ноября 2026

Первая версия.

- RADIUS-сервер: PAP, запрос кода (Access-Challenge), обязательный Message-Authenticator, распознавание повторов шлюза, ожидание подтверждения в пределах `MFA_GATE_PUSH_TIMEOUT`.
- Сценарий входа: блокировка после ошибок, проверка пароля локально или в LDAP / AD, политика, второй фактор. Постоянные коды причин отказа.
- Подтверждение на телефоне с подписью ECDSA P-256 из Android Keystore. Доставка через FCM, а также экспериментально через HMS и UnifiedPush; без push — прямой опрос сервера.
- Коды TOTP по RFC 6238 с защитой от повторного использования.
- LDAP / Active Directory: несколько контроллеров, LDAPS и STARTTLS, вложенные группы, диагностика.
- Политики по ресурсам и группам.
- REST API v1 с описанием OpenAPI, ключи API с правами и ограничением адресов, Device API v1.
- Веб-панель с ролями «Главный администратор», «Администратор», «Оператор», «Аудитор»; второй фактор обязателен.
- Журнал аудита с выгрузкой CSV, история входов, экран проблем входа.
- Docker Compose и `mfagatectl`: установка, обновление с автоматическим откатом, резервные копии, восстановление, диагностика, аварийный код администратора.
- Приложение MFA Gate Authenticator в сборках gms (с FCM) и foss (без сервисов Google).

Не вошли: RADIUS Accounting и атрибуты ответа ([Планы развития](Планы-развития.md)).
